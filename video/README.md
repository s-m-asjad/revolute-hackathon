## Tips

- **H.264 + AAC**, 1080p if possible, 30 fps  
- Keep each file under ~80 MB for smooth GitHub rendering, or use [Git LFS](https://git-lfs.com/)  
- Film **overhead** + a side angle if you can; show labels on ingredients  
- End hero clip on plated sandwich + “Order up!”
